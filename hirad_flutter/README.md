# پروژه فلاتر «باشگاه بدنسازی هیراد» (Hirad Flutter Native App)

نسخه بازنویسی‌شده کامل و کاملاً نیتیو (Pure Native Flutter / Dart) سامانه مدیریت ورزشکاران باشگاه بدنسازی هیراد با ساختار ماژولار، کدنویسی تمیز (Clean Architecture)، بدون وابستگی به وب‌ویو یا شل PWA، و آماده کامپایل بومی به فایل‌های نصبی **Android APK** و **iOS IPA**.

---

## 🏗️ ساختار پروژه (Project Architecture)

پروژه دقیقاً طبق مشخصات معماری درخواستی در `hirad_flutter` سازمان‌دهی شده است:

```
hirad_flutter/
├── pubspec.yaml                  # پیکربندی پکیج‌ها و تنظیمات متریال
├── analysis_options.yaml         # قوانین تجزیه و تحلیل استاتیک کد Dart
├── test_runner.dart              # مجموعه تست‌های واحد الگوریتم‌های اختصاصی
├── lib/
│   ├── main.dart                 # نقطه ورود، تنظیمات پوسته و RTL
│   ├── models/
│   │   └── athlete.dart          # مدل داده تایپ‌شده و امن (Null-safe) ورزشکار
│   ├── data/
│   │   └── athlete_repository.dart # لایه ذخیره‌سازی محلی با داده‌های اولیه واقعی
│   ├── screens/
│   │   ├── athlete_list_screen.dart     # لیست ورزشکاران به سبک واتساپ
│   │   ├── athlete_profile_screen.dart  # صفحه اختصاصی پروفایل ورزشکار
│   │   └── registration_form_screen.dart # فرم ثبت و ویرایش (Modal Bottom Sheet)
│   ├── widgets/
│   │   ├── avatar.dart                  # تولید آواتار حروف اول و انتقال Hero
│   │   ├── status_badge.dart            # بج وضعیت تسویه/بدهی و دوره تمرینی
│   │   ├── financial_card.dart          # کارت اطلاعات مالی و شهریه
│   │   ├── alphabet_quick_index.dart    # نوار پرش الفبایی با حباب پیش‌نمایش
│   │   ├── jalali_date_picker_dialog.dart # تقویم خورشیدی شمسی جلالی
│   │   └── theme_toggle_button.dart     # دکمه چرخان سوییچ روز و شب
│   ├── utils/
│   │   ├── jalali.dart                  # موتور محاسبات تقویم شمسی جلالی
│   │   └── validation.dart              # الگوریتم رقم کنترل کد ملی و شماره موبایل
│   └── theme/
│       └── app_theme.dart               # توکن‌های طراحی، رنگ‌ها و فونت Vazirmatn
```

## ⚡ پیاده‌سازی و انطباق الگوریتم‌های هسته (Core Algorithms)

### ۱. الگوریتم رسمی رقم کنترل کد ملی ایران (`validation.dart`)
- **عملکرد:** بررسی دقیق ۱۰ رقمی بودن، رد ارقام تکراری (مانند `1111111111`) و ضرب اوزان معکوس ۱۰ تا ۲ در ۹ رقم اول و مقایسه باقیمانده بر ۱۱ با رقم کنترل دهم.
- **تست واحد:** ۱۰۰٪ تست‌های واحد با موفقیت پاس شدند (`test_runner.dart`).

### ۲. موتور تقویم شمسی جلالی بدون وابستگی (`jalali.dart`)
- **عملکرد:** تبدیل ریاضی نجومی میلادی به جلالی و برعکس، محاسبه سال‌های کبیسه، محاسبه طول ماه‌های ۳۱، ۳۰ و ۲۹/۳۰ روزه، محاسبه خودکار سن از تاریخ تولد، و محاسبه مدت سابقه عضویت (مانند «۳ ماه عضویت» یا «۱ سال و ۵ ماه عضویت»).
- **تست واحد:** صحت محاسبات با تاریخ‌های مرجع (از جمله نوروز ۱۴۰۳) به طور کامل تایید شد.

### ۳. آواتار دایره‌ای با حروف اول یکتا (`avatar.dart`)
- **عملکرد:** استخراج حرف اول نام و نام خانوادگی به خط فارسی (مانند «ا ر» برای امیرحسین رضایی)، هش نام برای انتساب یک رنگ ثابت از پالت اختصاصی باشگاه، و سوئیچ خودکار به عکس در صورت وجود فایل تصویر.
- **انتقال عنصری مشترک (Shared-Element Transition):** پیاده‌سازی با ویجت نیتیو `Hero(tag: 'avatar-$id')` برای اجرای روان با نرخ ۶۰ فریم بر ثانیه بین لیست و صفحه پروفایل.

## 🎨 رفع کلیه ایرادات رابط کاربری نسخه قبلی

1. **یکپارچگی نقطه وضعیت در تمام سطرها:** تمامی سطرهای لیست بدون استثنا دارای نقطه وضعیت رنگی (سبز برای تسویه کامل، قرمز برای دارای بدهی) هستند.
2. **اصلاح آواتار پروفایل:** حذف هرگونه آیکون تیک متفرقه در مرکز آواتار؛ آواتارها با حروف اول شفاف یا عکس واقعی رندر می‌شوند.
3. **اصلاح چیدمان فیلد کد ملی:** عنوان در بالا («کد ملی») و مقدار عدد در سطر زیرین قرار دارد، و بج تایید ثبت‌احوال در کنار ارقام قرار گرفته است.
4. **فیلد رسمی دوره و رشته تمرینی:** فیلد `trainingCategory` به عنوان فیلد استاندارد با منوی کشویی در فرم ثبت/ویرایش و به عنوان بج در پروفایل پیاده‌سازی شد.
5. **یکدست بودن استایل دکمه‌ها:** تمام دکمه‌های اکشن به فرمت استاندارد ۴۰ پیکسلی با فیدبک لمسی تبدیل شدند و دکمه بازگشت از آیکون استاندارد راست‌به‌چپ بهره می‌برد.
6. **نوار پرش الفبایی با هدف لمسی استاندارد:** ارتفاع دکمه‌های الفبا حداقل ۳۶ پیکسل بوده و حباب پیش‌نمایش شناور شناور هنگام لمس یا اسکراب فعال می‌شود.

## 📱 راهنمای اجرا و بیلد خروجی APK

برای اجرای پروژه روی شبیه‌ساز یا گوشی اندروید/iOS:

```bash
cd hirad_flutter

# دریافت وابستگی‌های فلاتر
flutter pub get

# اجرای برنامه به صورت زنده
flutter run

# ساخت فایل نصبی خروجی اندروید (Release APK)
flutter build apk --release

# خروجی APK در مسیر زیر تولید می‌شود:
# build/app/outputs/flutter-apk/app-release.apk
```
