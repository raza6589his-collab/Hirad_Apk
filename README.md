# سامانه مدیریت ورزشکاران باشگاه ورزشی «هیراد» (Hirad)

یک اپلیکیشن مدرن، سریع، آفلاین‌محور و واکنش‌گرا (Mobile-First) با الهام از رابط کاربری روان و لیست چت واتساپ (WhatsApp-Style)، به همراه انیمیشن‌های ظریف میکرو (Micro-animations)، تقویم شمسی جلالی، اعتبارسنجی کد ملی و شماره موبایل ایران، و پشتیبانی کامل از حالت‌های روز و شب (Light/Dark Mode).

---

## 🌟 ویژگی‌های کلیدی اپلیکیشن

### ۱. صفحه ثبت و ویرایش ورزشکار (Add / Edit Athlete)
- باز شدن به صورت **Bottom Sheet تمام صفحه** با انیمیشن فنری نرم (~250-300ms ease-out).
- دسته‌بندی فیلدها در بخش‌های مجزا:
  - **مشخصات فردی:** انتخاب و آپلود عکس پروفایل با انیمیشن و دایره پالسی، نام، نام خانوادگی، انتخاب تاریخ تولد شمسی.
  - **اطلاعات تماس و هویتی:** شماره موبایل (شروع با ۰۹ و ۱۱ رقمی)، کد ملی ۱۰ رقمی با اعتبارسنجی الگوریتم رسمی ثبت احوال ایران.
  - **عضویت:** تاریخ شروع عضویت به صورت تقویم جلالی (پیش‌فرض امروز و قابل تغییر).
  - **مالی و شهریه:** مبلغ شهریه پرداختی (اجباری و جداسازی سه‌رقمی) و بدهی باقی‌مانده (اختیاری).
- **اعتبارسنجی زنده پس از ترک فیلد (On Blur):** حاشیه قرمز ملایم و نمایش پیام خطا بدون آزار کاربر در حین تایپ.
- **دکمه ثبت چسبان (Sticky):** فعال شدن در صورت معتبر بودن تمام فیلدها همراه با نشانگر لودینگ داخلی (Spinner).
- **افکت تایید ثبت:** بسته شدن فرم، انیمیشن فلش سبز ملایم در سطر ورزشکار جدید، پرتاب کانفتی شادباش، و توست ۲.۵ ثانیه‌ای.

### ۲. لیست ورزشکاران (طرح واتساپ - WhatsApp-Style Roster)
- **نوار عنوان بالا:** نام باشگاه هیراد، تعداد کل ورزشکاران، آیکون جستجو، منوی فیلتر/مرتب‌سازی، دکمه تازه‌سازی و سوییچ تم شب/روز.
- **جستجوی زنده:** فیلتر آنی بر اساس نام، نام خانوادگی، شماره موبایل و کد ملی.
- **سطرهای ورزشکاران:**
  - آواتار دایره‌ای (عکس اختصاصی یا حروف اول با رنگ اختصاصی).
  - نام و نام خانوادگی بولد.
  - وضعیت پرداخت (تسویه کامل به رنگ سبز یا میزان بدهی به رنگ قرمز).
  - تاریخ ثبت‌نام در لبه راست (مانند زمان پیام‌ها در واتساپ).
  - نقطه وضعیت رنگی (سبز برای تسویه، قرمز چشمک‌زن برای بدهی).
- **دسته‌بندی الفبایی (ا، ب، پ، ...) و نوار پرش سریع کناری (Alphabet Index Jump)** برای پیمایش سریع در باشگاه‌های بزرگ.
- **انتقال عنصری مشترک (Shared-Element Transition):** جابجایی و بزرگ شدن نرم عکس و نام ورزشکار از لیست به صفحه پروفایل با Framer Motion `layoutId`.
- **کشیدن سطر به چپ (Swipe Action):** دسترسی سریع به تماس تلفنی، پیامک، و حذف.
- **مرتب‌سازی و فیلترها:** بر اساس حروف الفبا، بدهکاران در ابتدا، جدیدترین یا قدیمی‌ترین ثبت‌نام‌ها، و فیلترهای سریع (همه / دارای بدهی / تسویه کامل).
- **دکمه شناور FAB (+):** با طراحی ارگونومیک برای استفاده با یک دست.

### ۳. صفحه اختصاصی پروفایل ورزشکار (Athlete Profile)
- **هدر با ترنزیشن مشترک:** عکس بزرگ و نام برجسته که از لیست گسترش یافته است.
- **دکمه‌های اقدام سریع:** تماس مستقیم تلفنی، ارسال پیامک، و چت مستقیم در واتساپ (`wa.me`).
- **کارت‌های اطلاعاتی تفکیک‌شده با انیمیشن ورود مرحله‌ای:**
  - وضعیت مالی و شهریه (مبلغ پرداختی، باقی‌مانده یا بج تسویه کامل).
  - اطلاعات تماس و کد ملی با امکان کپی در کلیپ‌بورد و بج تایید ثبت‌ احوال.
  - تاریخ تولد شمسی به همراه محاسبه سن جاری (مثال: ۲۵ سال).
  - تاریخ عضویت به همراه محاسبه مدت سابقه در باشگاه (مثال: ۳ ماه عضویت).
  - یادداشت‌های مربی و پرونده پزشکی.
- **دکمه‌های ویرایش و حذف:** با دیالوگ تاییدیه دو مرحله‌ای امن برای جلوگیری از حذف تصادفی.

### ۴. تقویم شمسی جلالی اختصاصی (Jalali Solar Calendar Picker)
- کامپوننت تقویم تعاملی شمسـی بدون باگ سال‌های کبیسه.
- امکان جابجایی سریع بین ماه‌ها و سال‌ها (برای تاریخ تولد و تاریخ عضویت).
- دکمه پرش به «امروز».
- نمایش ارقام و ماه‌های فارسی (فروردین تا اسفند).

### ۵. حالت تیره و روشن (Dark / Light Mode)
- سوییچ چرخان ۳۶۰ درجه‌ای با آیکون‌های خورشید و ماه.
- ترنزیشن رنگی ۳۰۰ میلی‌ثانیه‌ای نرم (Crossfade).
- شناسایی خودکار پوسته سیستم‌عامل کاربر (System Theme Preference) و ذخیره‌سازی انتخاب در حافظه محلی.

## 🚀 راهنمای اجرا

اپلیکیشن در حال حاضر بر روی پورت ۳۰۰۰ به صورت زنده در حال اجراست:
```bash
# آدرس دسترسی محلی:
http://localhost:3000/
```

### ساخت نسخه نهایی (Production Build):
```bash
npm run build
```

### خروجی برای اندروید یا iOS (با Capacitor):
برای تبدیل این پروژه به فایل نصبی موبایل (APK / IPA):
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init Hirad com.hirad.fitness
npx cap add android
npm run build
npx cap copy
npx cap open android
```
سپس در Android Studio خروجی APK را تهیه نمایید.
